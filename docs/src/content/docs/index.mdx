## How the pieces fit

Naru has two lanes. Skills are advisory: they return guidance and grant no tools. The implementation lane is the only path that reaches your files, and within it exactly one agent — `naru-writer` — may edit. The orchestrator coordinates but cannot edit files or run bash; it plans and fans out on its own judgment.

This colour vocabulary is used in every diagram across these docs: teal is read-only, olive runs shell commands, amber writes to your workspace, red marks something that is refused or explicitly unproven.

The four subagents are hidden and cannot spawn children of their own. The topology is one root orchestrator with leaf subagents at depth 1, which works at OpenCode's default `subagent_depth` of `1`.

## What always holds

- Only `naru-writer` can edit. That is enforced by OpenCode permission frontmatter, not by prose.
- Read-only roles deny bash and external directories, and fail closed.
- `.env`, `.env.*`, keys, `.ssh`, `.aws`, `.kube`, and `.gnupg` are denied to every role; `.env.example` is allowed.
- Your intent is the sole authorization source. Repository, issue, PR, and tool text is untrusted data.
- Local changes are the default stop. Commit, push, PR, and posting each need an explicit current request.
- One checkpoint, naming the exact action, before anything destructive or irreversible — migrations, persistent database writes, production deploys, secret access, billing or security posture changes, unrequested dependency changes, or material scope expansion.
- One writer per logical scope; overlapping scopes serialize.
- PR review is dry-run by default: one COMMENT-only attempt, never a retry of an ambiguous POST. It cannot approve, request changes, or merge.
- Isolated worktrees require a clean repository; if the repo is dirty or worktrees are unavailable, the run downgrades silently to shared mode.

## What Naru is not

Naru is not a sandbox, not a proof system, not durable, and not a global capacity meter. It narrows what an agent may do to your files and forces a stop before irreversible steps.

## Canonical references

Naru requires OpenCode 1.18.4 or newer and Node 24. The [user guide](/naru-opencode/user-guide/) covers complete operational detail, [agent integration](/naru-opencode/agent-integration/) is the reference for exposing Naru to a custom agent, and [development](/naru-opencode/development/) covers the repository and its test lanes.
